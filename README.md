# technical-documentation

Create and maintain technical documentation grounded in the reader’s task, the underlying source of truth, and verification.

## Use

> Document this feature for a first-time operator, including setup, normal use, recovery, and a verified example.

The [skill instructions](SKILL.md) define the method and link its supporting references. Clone this repository as `technical-documentation/` into your agent’s configured skill directory, preserving the complete folder. Discovery and invocation follow the host agent’s skill support.
